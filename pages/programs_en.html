• MoveCalcR – R library providing tools for the analysis and visualization of locomotor activity data in laboratory animals.
  • JStatML-R – open-source R-based tool for fast, automated, and user-friendly multi-group statistical analysis, offering statistical tests and result visualizations.
  • PickShot – Python library for analyzing images from confocal microscopy and flow cytometry, using CNNs (deep learning) to automatically detect and discard low-quality images.
  • JIMG-analyst-tool – Python library for high-resolution confocal microscopy and flow cytometry image analysis.
  • scRNAbaseR – R library for advanced single-cell data analysis based on UMI without cell barcodes.
  • scRNAbase – toolkit for preprocessing single-cell data based on UMI without cell barcodes.
  • CellMaNam – R library for cell naming based on cell markers and Fisher's statistics.
  • GTF-tool – R library for advanced processing of genome annotation files (GTF/GFF).
  • CSSG – R library for high-resolution analysis and classification of cell subtypes in single-cell studies.
  • JSEQ_scRNAseq – tool for analyzing single-cell sequencing data, enabling efficient processing and interpretation of results.
  • GEDSpy – advanced Python library for quick retrieval and analysis of gene function data from various sources.
  • BioSRA – program facilitating the download of large biological datasets from next-generation sequencing (NGS) from NCBI databases.
  • JIMG – Python library for processing confocal microscope images, with annotation capabilities for further analysis using AI algorithms.
  • JBioSeqTools – versatile Python library for preparing and processing genetic sequences for the creation of therapeutic viral plasmids.
  • SQL-db – sample database project in Oracle SQL, designed for clinical research.
